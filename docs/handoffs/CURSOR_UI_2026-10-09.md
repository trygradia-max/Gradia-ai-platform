## Visual direction: charcoal, silver and violet

Calm operating software for a solo detailer or busy shop team. Strong hierarchy,
readable evidence and obvious next actions. Keep the existing violet identity;
lift the almost-black surfaces so cards, inputs and panes are easier to distinguish.
Use existing semantic CSS variables, not per-component raw colors.

| Token / role | Target |
| --- | --- |
| Canvas | #101217 |
| Card / sidebar surface | #181B22 |
| Raised surface / popover | #222630 |
| Hover surface | #2A303C |
| Decorative divider | #303642 |
| Input/control boundary | #64748B (verify actual adjacent colors) |
| Primary text | #F4F5F7 |
| Secondary text | #A5ADBA |
| Primary filled action | #7C3AED with #FFFFFF text |
| Primary hover | #6D28D9 |
| Links / focus / selected emphasis | #A78BFA |
| Success | #4ADE80 |
| Attention / held | #FBBF24 |
| Error / destructive | #FB7185 |

Calculated opaque-pair contrast: white/primary 5.70:1, secondary/raised 6.69:1,
control boundary/raised 3.18:1, link/surface 6.33:1. Validate rendered opacity
and states independently.

Use status colors only for status, accompanied by text/icons. Preserve the
existing dark-first mode; no new theme switch or theme framework in this pass.
Keep Geist and the current compact type scale. Use 6px inputs/buttons, 10px cards,
16px dialogs; consistent spacing; subtle borders; at most one dominant primary
CTA per task region. Avoid ornamental gradients, glass panels, animated borders,
fake charts and decorative dashboard metrics. Keep reduced-motion support.
