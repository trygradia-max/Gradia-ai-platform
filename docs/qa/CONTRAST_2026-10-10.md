The live preview still painted `outline-ring/50` (2.62:1) because the
dev CSS pipeline did not rebuild `globals.css`. Source now removes that
universal 50% outline, paints `:focus-visible` with solid `--ring`, and
`FocusStyles` repeats the founder hexes so Tailwind cannot rewrite them
to `/50`. Approvals badge text moved from `#7c3aed` on 15% primary (2.70)
to `--accent-text` (5.65). Sidebar `muted-foreground/70` (4.40 at 11px)
was dropped.
